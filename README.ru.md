# DIY DPN Router на старом ноутбуке

[English](README.md) · [Русский](README.ru.md)

Самодельная VPN Wi-Fi система с раздельной настройкой двух сетей.

Превращает старый ноутбук с Windows в домашний VPN-шлюз, который обходит блокировки сайтов в России с помощью любого VPN-клиента (Outline, Clash, Amnezia, WireGuard и т.д.), со вторым роутером, раздающим зарубежный Wi-Fi для устройств, которым он нужен.

## Возможности

- **Две сети** — одна для умного дома и госуслуг, вторая для YouTube / Telegram / Netflix.
- **VPN-клиент** — работает на ноутбуке с Windows (в примере — Outline, но подойдёт любой клиент).
- **Зарубежный Wi-Fi** — раздаётся через второй роутер Huawei.
- **Всегда онлайн** — полная защита от сна, гибернации и выключения.

## Начало работы

1. Установите любой VPN-клиент (Outline, Clash, v2rayN, Amnezia и т.д.) на ноутбук.
2. Подключите ноутбук к основному роутеру (Keenetic) по Ethernet.
3. Расшарьте VPN-соединение через второй Ethernet-порт на роутер Huawei.
4. Примените команды `powercfg` из [`no_sleep_forever.md`](no_sleep_forever.md), чтобы отключить сон.
5. Готово! Huawei раздаёт зарубежный интернет.

## Как это работает

- Windows ICS (общий доступ к интернету) раздаёт VPN-туннель по Ethernet.
- Роутер Huawei получает NAT из VPN-туннеля.
- Все устройства за Huawei получают зарубежный IP (например, Нидерланды).

## Если что-то не работает

| Проблема | Решение |
|---|---|
| Нет интернета на устройствах за Huawei | Проверьте, что ICS включён на VPN-адаптере, а не на физической сетевой карте |
| Соединение падает ночью | Перепроверьте шаги `powercfg` — ноутбук всё ещё уходит в сон |
| ICS сбрасывается после перезагрузки | Windows иногда выключает ICS при рестарте; выключите и снова включите общий доступ |
